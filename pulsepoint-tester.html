● PULSEPOINT TESTER

Make sure your Spring Boot app is running
Start here. A Source is any device sending data — a vehicle, server, or sensor. Create one first, then copy its id — you'll need it in every other tab.
POST Register a new source /api/sources ▼
Example: Vehicle-001, Server-Prod, Sensor-A
Example: VEHICLE, SERVER, SENSOR
GET List all sources /api/sources ▼
No input needed. Returns all registered sources.
GET Get one source by ID /api/sources/{id} ▼
Use the id returned when you created the source above
Send data readings from a source. Use the source id from the Sources tab. Every ingest automatically checks alert rules and fires alerts if thresholds are crossed.
POST Send a single reading /api/ingest/{sourceId} ▼
Example: speed, battery, temperature, rpm
Example: kmh, %, celsius, rpm
POST Send multiple readings at once (batch) /api/ingest/{sourceId}/batch ▼
Each object must have metric and value. unit and timestamp are optional.
Read data back. Query historical readings, get the latest value per metric, or get statistics (avg / min / max) over a time range.
GET Latest reading per metric /api/sources/{sourceId}/latest ▼
Returns the most recent reading for each metric this source has ever sent
GET Historical readings for a metric /api/sources/{sourceId}/data?metric=&from=&to= ▼
Format: YYYY-MM-DDTHH:MM:SS — results returned newest first
GET Summary — avg / min / max over time range /api/sources/{sourceId}/summary?metric=&from=&to= ▼
Alert rules tell the system when to fire an alert. Example: "if speed > 100, fire a HIGH alert." The rule is checked automatically on every ingest. Operators: GT (>), LT (<), GTE (>=), LTE (<=), EQ (=)
POST Add an alert rule to a source /api/sources/{sourceId}/rules ▼
Must match the metric name used during ingest
Alert fires when: metric value [operator] threshold
GET List all rules for a source /api/sources/{sourceId}/rules ▼
Alerts are fired automatically during ingest. You never create them manually. List them here with optional filters, then resolve them. An alert with resolvedAt = null is still open.
GET List alerts — with optional filters /api/alerts?sourceId=&severity=&resolved= ▼
All filters are optional. Leave blank to get everything.
PATCH Resolve an alert /api/alerts/{alertId}/resolve ▼
Use the id from the list above. Sets resolvedAt to now. Cannot be undone.
