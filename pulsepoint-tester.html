Alert rules define when alerts fire. Add a rule like "speed GT 100 → HIGH" and every future ingest for that metric on that source will be evaluated against it automatically. The metric name must exactly match what you send during ingest.
POST Add an alert rule to a source /api/sources/{sourceId}/rules open ▲
Must exactly match the metric name used in ingest
Alert fires when: incoming value [operator] this threshold
GET List all rules for a source /api/sources/{sourceId}/rules open ▼
Alerts fire automatically during ingest — you never create them manually. An alert with resolvedAt: null is open. Use the resolve endpoint to close it. All filters below are optional and combinable.
GET List alerts — with optional filters /api/alerts open ▲
All three filters are optional. Leave any blank to skip that filter.
PATCH Resolve an alert /api/alerts/{alertId}/resolve open ▼
Use the id from the list above. Sets resolvedAt to now. Cannot be undone.
